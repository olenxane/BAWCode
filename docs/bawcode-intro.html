Coding Agent · 基座介绍

BAWCode　纯 Python · 纯终端 · 本地优先的
AI 编码 Agent 基座

一次回合由一份 JSON 工作流驱动；文件改动前有快照可回滚；工具调用有三档权限可切换；上下文超预算就自动压缩；外部能力以 MCP 服务器、技能包、子代理、扩展点四种形态接入。

Python · 无框架依赖 Rich TUI · 本地运行 OpenAI 兼容 · 多 Provider 工作流 · JSON 编排 MCP 客户端 · 外部工具桥接
查看架构 → 外置工作流示例
01 / WORKFLOW

回合可见可编排

一轮 agent 回合不再硬编码。系统提示词注入 / 技能清单 / 规划 / 执行 / 通用 LLM 阶段全部是节点，改 JSON 就能增删。

02 / SAFETY

三重文件安全网

写文件前留原始字节快照；/undo 走确定性还原而非模型逆操作；delete_file 进回收站，rm/del 硬拒绝。

03 / POLICY

三档权限可切

Auto / Manual / Full 三档工具策略贯穿工具循环；只读工具放行、危险命令硬拦、其他按指纹确认，"始终允许"按工具白名单。

04 / EXTENSIBLE

四层扩展面

MCP 服务器 / 技能包 / 子代理 / HTTP 扩展点。加上 JSON 工作流与 ^{{var}}^ 提示词模板，几乎每个环节都可挂。

§ 03

一次回合的生命周期

turn lifecycle

用户在输入框发出任务后，main.py 的 _AgentRunner 开后台线程跑 _agent_turn；主循环保持可交互，用户可继续输入（按 ui.busy_send_mode 队列或中断）。每个节点通过 TurnIO 回调与 UI 对话，UI 从不反向调用引擎。

01
begin_turn

记录用户消息绝对序号 msg_index，写入 data/snapshots 轻量清单，建立本回合对账基线。

02
workflow.load

读 data/workflows/<active>.json；损坏或缺失时告警并回退内置 DEFAULT_WORKFLOW（3 节点最小链）。

03
节点执行

按节点链顺序跑：system_prompt → skill → plan → execute / llm；每步 _check_cancel 检查取消。

04
tool_loop

调用 llm.chat（SSE 流式）→ 策略判定（allow/confirm/deny）→ 执行 → 会话入库；轮次上限按 has_recent_progress 自动续期。

05
finalize_turn

会话收尾：非白名单工具结果剥离、超大结果外置 data/toolcalls、上下文超阈值时按 state_snapshot XML 压缩。

06
end_turn

回合快照落盘（blob + index.json，原子写）；重扫工作区与清单对账；子代理运行时解绑；流式槽位清零。

§ 04

外置工作流

data/workflows/default.json

工作流不是代码，是数据。每轮回合按 data/workflows/<active>.json 的节点链跑；用户想"不要计划阶段"、"加一步 review"、"多一轮 llm 总结"，都可以直接在 JSON 里增删，或用 /workflow 打开 gui/workflow_editor.py（PySide6）可视化编辑。引擎不硬编码取舍。

5 种内置节点执行器：system_prompt / skill / plan / execute / llm。前四个语义明确，llm 是最通用的兜底节点：max_rounds>0 走工具循环、=0 是单次问答；输出经 capture 字段存入 turn.captured，供后续节点提示词 ^{{var}}^ 渲染。

§ 05

工具与访问策略

register · policy · snapshot

工具通过 @register 装饰器注册到全局 _registry，被 llm.chat() 导出为 OpenAI function 定义；每个工具函数默认接收一个 description 参数（一句话说明本次调用意图），执行前被剥离，回合末写入会话作为"调用记录"。MCP 桥接进来的外部工具走完全相同的路径。

工具调用前先过 policy.evaluate，得到 allow / confirm / deny 三态；manual 与 auto 下，只读安全工具（read/search/glob/list_directory/memory_add_fact/rag_add/load_skill）直接放行，其他按模式与指纹白名单处理。rm、format、shutdown 等危险命令无论模式一律 deny。

core/tools.py · 工具注册示例 
from core import register

@register(
    name="read",
    description="按行读取文本文件，支持 offset/limit 分页",
    usage="read(file_path, offset?, limit?)",
    schema={
        "type": "object",
        "properties": {
            "file_path": {"type": "string"},
            "offset":    {"type": "integer"},
            "limit":     {"type": "integer"},
        },
        "required": ["file_path"],
    },
)
def read(file_path, offset=None, limit=None):
    # 实现体
    ...

文件写入类工具（write / edit_file / multi_edit / delete_file）在真正落盘前调用 snapshot.capture_before，把原始字节写进 data/snapshots/{project}/{session}/{turn_index}/；用户 /undo 时按 md5 门禁还原——用户事后自己改过的文件自动跳过，避免覆盖用户劳动。delete_file 不销毁，而是移入 data/trash/{project_id}/，可 /undo 恢复，/clear-trash 才真正清空。

§ 06

配置与目录

data/config.json

配置分区（default_config）

  • providers多 Provider 列表；每项含 base_url/api_key/models[]/temperature；model_name = provider_id-model_id
  • task_models按 plan / code / review 分配模型；空则回落激活模型
  • prompt提示词目录与文件列表（system/plan/steps/compress）
  • ui主题、发送/换行键、busy 模式（queue/interrupt）、字号、树折叠等
  • llmretry_times / retry_delay / stream（SSE 开关）
  • context工具白名单、预算 token、普通/大型工具行内限额、外置目录
  • workflowactive 工作流名、max_rounds 覆盖、max_rounds_extensions 续期次数
  • memory长期记忆路径、自动压缩阈值、保留尾段 token 预算、摘要硬上限
  • skills技能开关、目录、元数据 token 预算
  • subagent启用、最大轮次、结果字符上限、query 默认轮数、角色目录
  • mcp启用、servers 声明、超时、自动重连、工具过滤
  • snapshot启用、目录、最大回合数、单文件大小上限、清单文件数上限
  • log全局 level、按模块覆盖、stderr 同步、保留天数
  • external_apisHTTP 扩展点 URL 映射（null = 走本地默认逻辑）

目录布局

  • core/引擎与所有核心模块（21 个 .py）
  • core/prompts/系统/计划/步骤/压缩提示词模板（Markdown）
  • gui/PySide6 工作流编辑器
  • data/config.json主配置文件
  • data/workflows/*.json工作流定义
  • data/agents/*.json子代理角色 persona
  • data/commands/命令插件目录
  • data/skills/全局技能包；项目级在 {workspace}/.bawcode/skills
  • data/memory/Agent.md 与 Projects/ 长期记忆
  • data/sessions/<pid>/按项目隔离的会话文件

§ 07

扩展点

4 层扩展面
MCP CLIENT

MCP 工具桥接

用官方 mcp Python SDK；每服务器专用事件循环线程同步桥接；stdio + Streamable HTTP/SSE；工具注册名 mcp__<server>__<tool>。

core/mcp.py · config.mcp.servers
SKILL PACK

技能包

SKILL.md + YAML frontmatter；启动只扫元数据进 [可用技能] 补充，正文经 load_skill 按需取；全局 data/skills/ 与项目级 .bawcode/skills/ 双层同名覆盖。

core/skills.py · tools.load_skill
SUBAGENT

子代理

独立上下文子代理跑大调研 / 审查；task 派发、query_subagent 查询过程；角色由 data/agents/<role>.json 定义 persona + 模型 + 工具权限。

core/subagent.py · tools.task
WORKFLOW JSON

工作流节点

回合管线由 data/workflows/*.json 声明；改 JSON 就等于改"这一轮 agent 该干什么"；llm 节点可捕获输出供后续节点提示词渲染。

core/workflow.py · gui/workflow_editor.py
PROMPT TEMPLATES

提示词模板

所有系统/计划/步骤/压缩提示词都是 core/prompts/*.md 文件，含 ^{{var}}^ 占位符；替换表由 prompt_loader.build_variable_context 统一构建。

core/prompt_loader.py
HTTP HOOKS

外部 API 扩展

external_apis 配置 → HTTP POST 处理器；事件：prompt_refine / plan_confirm / step_generate / memory_* / rag_* / computer_use / llm_request / tool_confirm；失败自动回落本地逻辑。

core/hooks.py · config.external_apis
