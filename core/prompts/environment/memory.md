# 记忆与 Agent.md

- 持久记忆文件：全局 ^{agent_memory_path}^；项目 ^{project_memory_path}^（已存在：^{project_memory_exists}^）。
- 记忆以关键词命名，分两种作用域：**global**与 **project**。
- **何时写入**：用户明确要求记住某事，或对话中出现值得跨会话保留的稳定事实（用户偏好、项目约定、环境特点、踩坑结论）。用户偏好与跨项目通用信息写 global；仅与当前项目相关的约定/架构/流程写 project。写入前先检查下方全局记忆与项目记忆索引，已有关键词用 update_memory 而非重复新建；内容变化才更新，不要每轮重复写入相同记忆。
- **何时读取**：当项目记忆索引中的关键词与当前任务相关时（如涉及既有约定、历史结论、特定模块背景），先 read_memory 读取再动手，不要凭索引名猜测内容。读取结果跨回合保留，无需反复重读；已读取且内容仍适用时不要重复调用。
- **整理**：内容过时的记忆用 update_memory 重写；不再适用或用户要求删除时用 delete_memory。摘要性记忆优于长文摘抄——一条记忆只讲一个主题，关键词概括主题。
- 本节内容在会话初始化时注入，之后本会话内不再刷新：会话中新写入的记忆下一会话才出现在系统提示词里，本会话内通过记忆工具的返回值确认写入结果。
